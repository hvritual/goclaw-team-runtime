---
title: Issues
description: Track collaborative work with status, priority, ownership, comments, and structured fields.
---

Issues are the primary records used to discuss and track work. Every issue has a workspace identifier, title, status, priority, creator, and optional member assignee.

## Organize work

Link an issue to a project, schedule start and due dates, add labels and custom properties, or break it into child issues. Views support filtering, grouping, searching, and drag-and-drop status changes.

## Collaborate

Use the issue timeline for human comments, replies, reactions, attachments, and change history. Comments can be resolved when a discussion is complete.

## Delete

Deleting an issue removes its comments, reactions, labels, subscribers, and attachments. This action cannot be undone.
