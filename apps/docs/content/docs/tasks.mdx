---
title: Tasks
description: Manage concrete member-owned actions independently or alongside projects and issues.
---

A task is a concrete action owned by a workspace member. Tasks are independent business records, not execution logs.

Each task can include:

- a title and description;
- status: `todo`, `in_progress`, `done`, or `cancelled`;
- priority: `urgent`, `high`, `medium`, `low`, or `none`;
- an optional member assignee;
- optional project and issue links;
- position, start date, due date, and completion time.

Use the **Tasks** page to create, edit, complete, or delete tasks. Links to projects and issues must stay inside the same workspace.

The command line supports `multica task list`, `multica task create`, `multica task update`, and `multica task delete`.
