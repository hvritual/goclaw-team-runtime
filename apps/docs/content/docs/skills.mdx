---
title: Skills
description: Maintain reusable workspace knowledge with structured content and supporting files.
---

A skill is a reusable knowledge package stored in a workspace. It has a name, description, primary content, configuration, and optional supporting files.

## Create or import

Create a skill directly in Multica or import a compatible archive. Skill names are unique inside a workspace.

## Supporting files

Use supporting files for examples, templates, references, or configuration that belongs with the skill. Paths are validated and the reserved primary file cannot be overwritten through the supporting-file API.

## Labels and access

Skills can use their own label namespace for organization. Workspace members can browse skills; edit and delete controls follow workspace permissions.
